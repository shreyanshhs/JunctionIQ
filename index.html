How the experiment works

Fixed timer switches after 18 seconds of green. Longest queue switches when the other direction has a longer queue. Q-learning chooses hold or switch using the green direction, two queue sizes grouped into bins, and elapsed green time grouped into bins.

Python trains the controller on 2,400 synthetic episodes when the server starts. Each second, the agent receives a reward of minus the number of waiting vehicles. It updates the value of its chosen action using the reward and the best estimated value of the next state. Evaluation uses a fixed policy on separate arrival streams.

All controllers start north–south green and share a 6-second minimum green, a 30-second maximum green, and a 2-second all-red clearance. Each green approach can serve one vehicle per second. Total wait adds the queued vehicles each second, including vehicles still waiting when the run ends.

This model assumes straight-through traffic, fixed discharge rates and an isolated junction. Results apply to this simulation.
